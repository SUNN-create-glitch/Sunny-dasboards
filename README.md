🎓 Student Management System

A simple and beginner-friendly Student Management System developed using Python as a B.Tech college project.

The project provides a console-based system to manage student records efficiently, including adding, viewing, searching, updating, and deleting student information.

---

👨‍💻 About the Project

The Student Management System is designed to demonstrate basic Python programming concepts such as:

- Functions
- Conditional statements
- Loops
- Lists and dictionaries
- File handling
- JSON data storage
- CRUD operations

Student records are stored locally using a JSON file.

---

✨ Features

- ➕ Add new student records
- 📋 View all student records
- 🔍 Search student by roll number
- ✏️ Update student information
- 🗑️ Delete student records
- 💾 Automatically save data in JSON format
- 🖥️ Simple command-line interface

---

🛠️ Technologies Used

- Python 3
- JSON
- Python Standard Library
